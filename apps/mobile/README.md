# EmotionSense AI Mobile

This directory contains the Flutter mobile client foundation for EmotionSense AI. It targets Android and iOS and intentionally contains no product features, capture, inference, persistence, authentication, backend integration, or analytics.

## Toolchain

- Flutter 3.44.8 stable
- Dart 3.12.2

The exact Flutter version is declared in `pubspec.yaml` and used by GitHub Actions. Use this version locally to keep formatting, dependency resolution, analysis, and generated output reproducible.

## Commands

From this directory:

```text
flutter pub get
dart format --output=none --set-exit-if-changed .
flutter analyze
flutter test
flutter run
```

## Generated-File Policy

- Source files generated by Freezed or other approved builders must never be edited manually.
- Generated Dart output required to build the application is committed beside its source declaration.
- Run `dart run build_runner build --delete-conflicting-outputs` after changing an annotated source file.
- Submit the source and corresponding generated changes in the same pull request.
- New generators require dependency review and an ADR when they create a cross-feature or difficult-to-reverse convention.

No generated Dart source exists in Milestone 0.2 because no domain or data models have been implemented.

## Architecture

`lib/app/` contains only application composition, routing, and theme foundations. `lib/core/` is reserved for stable cross-cutting capabilities. `lib/features/` is feature-first and follows the domain, data, and presentation boundaries documented in the project architecture.

Do not add a feature until its requirements, acceptance criteria, dependencies, and applicable ADRs are approved.
